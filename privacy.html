隱私權政策

Shorts 上傳器　·　最後更新：2026 年 9 月 9 日

一、這個應用程式的性質

「Shorts 上傳器」是一個個人自用工具，在經營者自己的電腦上執行， 用途是把自己製作的影片上傳到自己的 YouTube 頻道。 它沒有對外提供服務，沒有註冊機制，除了經營者本人以外沒有其他使用者。

二、存取哪些 Google 使用者資料

經授權後，本工具會使用下列 Google API 權限範圍：

  • https://www.googleapis.com/auth/youtube.upload　—　上傳影片到已授權的 YouTube 頻道
  • https://www.googleapis.com/auth/youtube.force-ssl　—　在自己上傳的影片下方張貼一則說明來源與授權的留言

除此之外不存取任何其他 Google 資料。

三、資料怎麼儲存

  • 授權後取得的存取憑證（access token 與 refresh token）只儲存在經營者本機的一個檔案裡
  • 不上傳到任何伺服器，不同步到雲端，不與任何人共享
  • 本工具沒有後端伺服器，也沒有資料庫

四、資料怎麼使用

憑證只用來呼叫上述兩個權限範圍所允許的操作：上傳影片、張貼留言。 不會用於分析、廣告、模型訓練，也不會轉售或轉讓給任何第三方。

五、Google API 服務使用者資料政策

本應用程式對 Google API 所取得資訊的使用與轉移，均遵守 Google API 服務使用者資料政策，包含「有限使用」（Limited Use）規定。

六、資料保留與撤銷

  • 刪除本機的憑證檔即可終止本工具的一切存取能力
  • 也可隨時在 Google 帳戶的第三方應用程式頁面 移除本應用程式的授權
  • 授權移除後，本工具無法再取得任何資料

七、兒童隱私

本工具不針對兒童，也不蒐集任何人的個人資料。

八、政策異動

本政策如有修改，會直接更新本頁面並修改上方的「最後更新」日期。
