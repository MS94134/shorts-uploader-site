Shorts 上傳器

一個給自己用的小工具，把做好的短影音自動上傳到自己的 YouTube 頻道。

這是什麼

「人生實驗室」頻道的影片製作流程跑在自己的電腦上。影片做完、母帶處理完之後， 這個工具透過 YouTube Data API v3 把成品連同標題、描述、標籤一起上傳到頻道， 並且一律先設為私人，等人工確認過內容才手動改成公開。

它會做的事

  • 上傳影片檔到經營者自己的 YouTube 頻道（預設私人）
  • 帶上事先寫好的標題、描述、標籤
  • 發一則說明來源與授權的留言

它不會做的事

  • 不讀取、不蒐集任何其他使用者的資料
  • 不對外提供服務，沒有註冊，沒有其他使用者
  • 不把任何資料傳給第三方

使用範圍

這個工具只由經營者本人在本機執行，用來管理自己的頻道， 不開放給任何其他人使用。授權憑證（token）只存在經營者自己的電腦上。
